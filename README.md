# Tic-Tac-Toe

## Problem

Choose a move for the current player in a 3-by-3 Tic-Tac-Toe game so that the AI plays optimally and cannot be beaten.

## Solution

The program models legal actions, board transitions, winners, and terminal states. It uses minimax to evaluate possible plays and selects a move that maximizes the current player's outcome, assuming both players play optimally.
